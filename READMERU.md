# Fllama

[English](README.md)

Fllama - десктопное приложение для работы с ИИ-агентами в локальных проектах. У каждой задачи свой агент, модель и история. Задачи можно запускать параллельно и проверять изменения файлов прямо в приложении.

## Запуск

Установите Node.js и Git. Из корня репозитория выполните:

```sh
cd src
npm ci
npm start
```

Git нужен для worktree и просмотра изменений. Подключите нужного агента:

| Агент | Как подключить |
| --- | --- |
| Codex CLI | Установите `codex`, войдите в аккаунт и убедитесь, что исполняемый файл доступен через PATH. |
| Claude Code CLI | Установите `claude`, войдите в аккаунт и убедитесь, что исполняемый файл доступен через PATH. |
| OpenCode | Установите `opencode` или укажите адрес работающего сервера в настройках. Перед запуском задачи откройте проект. |
| Ollama | Запустите Ollama и скачайте модель в разделе «Модели Ollama». |
| LM Studio | Запустите локальный сервер и проверьте его адрес в настройках. |
| OpenAI API / Anthropic API | Укажите ключ и адрес API в настройках. |

Интерфейс доступен на русском, английском, немецком и испанском. Язык меняется в разделе **Настройки → Интерфейс**.

| Дополнительная интеграция | Как подключить |
| --- | --- |
| Kiro, Hermes, Cline, Roo Code, Gemini CLI | Установите и авторизуйте нужный CLI. Откройте проект и выберите его в задаче. |
| Kilo Code CLI | Установите `kilo` в PATH, подключите провайдера через `kilo auth` и выберите Kilo Code CLI в задаче проекта. |
| OpenRouter, Gemini API, DeepSeek, Groq, xAI, Mistral, Kilo Gateway | Настройте провайдера в разделе **Настройки → Провайдеры**. Для Kilo без ключа выберите модель с суффиксом `:free`. |
| OpenAI-compatible | Укажите базовый URL API и при необходимости ключ. ID модели можно ввести вручную. |

## Работа с задачами

1. Откройте папку проекта или создайте задачу в разделе «Без проекта» для разговора без доступа к файлам проекта.
2. Выберите агента и модель, затем опишите задачу. Для Git-репозитория с коммитом доступен режим **Worktree**. Режим **Папка проекта** даёт агенту доступ к выбранной папке.
3. Запустите другую задачу для параллельной работы. Справа видны статус запуска, действия агента, файлы и Git diff.
4. Нажмите **Передать другому агенту**, чтобы перенести запрос и ответ в новую задачу. При передаче задачи с worktree следующий агент получает ту же рабочую копию с её изменениями.

Новый worktree создаётся из текущего коммита в ветке `fllama/…`. Незакоммиченные правки остаются в исходной папке. Задачи в одной рабочей копии выполняются по очереди. После удаления задачи её worktree и ветка остаются на диске. Слияние выполняется средствами Git.

Локальный сервер моделей можно включить в разделе **Настройки → Fllama как агент**.
